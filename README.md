# Jarvis AI Assistant

A voice-controlled AI assistant built with Python, Ollama, Speech Recognition, and Text-to-Speech.

## Features

- Voice Commands
- Speech Recognition
- AI Chat using Ollama
- Text To Speech
- Open Websites
- Tell Time
- Local AI (No OpenAI API Required)

## Technologies Used

- Python
- Ollama
- SpeechRecognition
- PyAudio
- pyttsx3

## Installation

```bash
pip install speechrecognition
pip install pyaudio
pip install pyttsx3
pip install ollama
```

## Run

```bash
python main.py
```
